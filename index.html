Remediation Activities

Targeted activities for Group A (12 students)

Visual Regrouping with Base-10 Blocks

Place Value
⏱️ 7 minutes 👥 Group A 🧱 Physical

Use physical base-10 blocks to demonstrate borrowing in subtraction. Have students practice with 2-digit problems using blocks before written work.

Materials Needed:

Base-10 blocks Individual slates Chalkboard

Steps:

  1. Demonstrate 53 - 27 using blocks
  2. Show how to "borrow" a ten
  3. Students practice with blocks
  4. Transfer to written notation

Number Line Jump Strategy

Subtraction
⏱️ 5 minutes 👥 Group A 📝 Visual

Draw number lines on the floor. Students physically "jump" backward to solve subtraction problems, building kinesthetic understanding.

Materials Needed:

Chalk Floor space

Partitioning Numbers Game

Place Value
⏱️ 8 minutes 👥 Group B 🎮 Game

Students break numbers into tens and ones, then rebuild them. Use playing cards to create random numbers for practice.

Materials Needed:

Playing cards Paper Pencils
