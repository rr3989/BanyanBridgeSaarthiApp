# Android app skeleton for BBSaarthi

This folder contains a minimal Android project skeleton created so you can open it in Android Studio and build an APK.

How to open and build

1. Open Android Studio.
2. Choose "Open" and select the `android/` folder in this workspace.
3. Let Gradle sync. If prompted to upgrade Gradle or Android Gradle Plugin, accept recommended versions.
4. Build > Make Project or build an APK via Build > Build Bundle(s) / APK(s) > Build APK(s).

Notes
- This is a minimal skeleton. Feature screens referenced in the main UI are placeholders (toasts). Implementations can be added under `app/src/main/java` and new activities/fragments under `res/layout`.
